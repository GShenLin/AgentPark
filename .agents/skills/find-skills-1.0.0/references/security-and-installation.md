# 安全审查与安装

Skill 可能包含提示词、脚本、依赖、MCP 配置和可执行文件，应按代码供应链处理。

## 安装前检查

对最终候选至少检查：

1. **来源**：平台详情是否能追溯到作者、原仓库和具体 Skill 路径。
2. **内容**：读取 `SKILL.md`、依赖清单、脚本、配置和安装说明。
3. **执行面**：识别 shell/PowerShell/Python/Node 脚本、二进制文件、生命周期脚本和提权命令。
4. **网络面**：列出外联域名、下载行为、远程脚本执行和遥测。
5. **秘密**：查找读取环境变量、Token、Cookie、SSH key、云凭证和浏览器资料的行为。
6. **文件系统**：检查写入范围、删除/覆盖、权限修改、启动项和全局配置修改。
7. **依赖**：检查锁文件、未固定版本、包安装命令以及来源不明的依赖。
8. **许可证与维护**：记录许可证、最近维护证据和已知问题；未知就明确标注未知。

平台提供的签名、扫描或评级是 `security_evidence`，不是跳过上述检查的理由。

## 风险分级

- `low`：纯文档指令，无脚本、无外联、无秘密访问。
- `medium`：存在可审查脚本或固定依赖，但权限与目标明确。
- `high`：涉及凭证、浏览器会话、系统控制、任意命令、远程下载执行或宽泛写权限。
- `unknown`：无法取得完整源码或关键依赖不可审查。

`high` 和 `unknown` 候选不得自动安装。必须解释原因并等待用户决定。

## 用户确认合同

执行安装前向用户展示：

- Skill 名称、版本、作者和原始来源；
- 仓库及具体路径；
- 风险级别与关键发现；
- 将运行的准确命令；
- 安装目标目录；
- 是否会安装依赖、访问网络或要求秘密。

只有用户对该候选和该目标目录明确确认后才能执行。

## 安装目标

- 默认：当前项目 `.agents/skills/<skill-name>/`。
- 用户明确要求共享安装时：`~/.agents/skills/<skill-name>/`。
- 不再写入旧项目根 `skills/`。
- 目标已存在时停止，比较版本与差异；未经确认不得覆盖。

## 安装策略

优先顺序：

1. 平台官方 CLI 能明确指定正确目标目录，并且已核对当前帮助信息；
2. 下载/检出到临时目录，审查后只复制所需 Skill 目录；
3. 手动复制经过审查的文件。

不得使用 `curl ... | sh`、`irm ... | iex` 或等价的远程脚本直接执行方式。

CLI 如果默认全局安装或目标不明确，先停止并选择可控的临时目录/手动复制流程。

## 安装后验证

1. 读取落盘后的 `SKILL.md`，确认名称、版本与预期一致。
2. 确认路径位于用户批准的项目级或用户级根目录内。
3. 检查安装过程没有额外修改项目外文件。
4. 通过 AgentPark Skill loader 验证可发现和加载。
5. 报告实际路径、版本、依赖以及任何待配置项。
