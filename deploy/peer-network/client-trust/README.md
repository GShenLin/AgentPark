# AgentPark 私有证书：新设备首次配置

本公开仓库不附带任何部署实例的根证书或证书指纹。请先为自己的服务器生成证书，
再把生成的 `AgentPark-Root-CA.crt` 和 `certificate-info.json` 放入本目录。
部署示例中的 `203.0.113.10` 是文档保留地址，使用前必须替换为自己的服务器 IP。

## Windows

核对 `certificate-info.json` 中的 SHA-256 指纹与证书管理员通过可信渠道提供的记录后，
在当前用户下运行 `install-windows.ps1`。脚本校验指纹后将根证书加入当前用户 Root 存储。
也可以手动导入证书，选择“当前用户 → 受信任的根证书颁发机构”。
使用独立证书库的浏览器或程序需要单独导入。不要通过关闭 TLS 验证代替安装信任。

## 手机和其他系统

将自己生成的公开根证书传到设备，并按系统要求安装；实际验证应用是否信任该证书。
不要分发 `.auth/private-ca`、根私钥或服务器签发私钥。

服务器叶证书可以定期更新；如果仍由同一根证书签发，客户端无需重复安装根信任。
更换服务器 IP 时，应重新签发受对应 IP 约束的下级 CA。
