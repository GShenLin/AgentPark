# AgentPark 私有证书：新设备首次配置

访问地址：https://203.0.113.10/

本目录只有公开根证书、核对信息和 Windows 安装脚本，不包含任何私钥或登录密码。

## Windows

在当前用户下运行 `install-windows.ps1`，将根证书加入当前用户的受信任根存储。
`build_and_run.bat` 启动时会自动调用此脚本：先校验证书指纹，已安装则跳过，未安装则导入；失败时停止启动并显示错误。
或者手动导入 `AgentPark-Root-CA.crt`，选择“当前用户 → 受信任的根证书颁发机构”。
安装后重新打开浏览器页面。不要通过关闭证书验证或忽略浏览器警告来代替安装信任。
Python 标准库默认 TLS 上下文在 Windows 上读取系统证书存储；本机 AgentPark 已验证可使用这个信任重连。
使用独立证书存储的浏览器或程序，需要在该程序里单独导入根证书。

## 手机和其他系统

把 `AgentPark-Root-CA.crt` 传到自己的设备，按系统的 CA 证书安装流程添加信任。
不同系统和应用对用户安装的 CA 支持不同，需要在目标设备上实际验证。
不要把 `.auth/private-ca` 或服务器上的签发私钥复制到手机。
