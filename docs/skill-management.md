# Skill 管理

设置中的「Skill 管理」汇总项目、用户和自定义目录中的 Skill，展示名称、用途、版本、完整说明和资源列表。

## 加载来源

默认来源按顺序为项目 `.agents/skills`、运行 AgentPark 的系统用户的 `~/.agents/skills`，随后是「管理加载路径」中添加的目录。自定义配置保存到本机项目的 `.cache/skill-roots.json`；管理页与节点运行时共用这份配置。

添加的是包含多个 Skill 文件夹的根目录，不是单个含 `SKILL.md` 的文件夹。自定义目录须为服务端的绝对路径，不得与已有根目录重叠或嵌套。移除加载路径只修改配置，保留目录及全部文件。

Skill 按相对路径标识，例如 `Game/Design/combat`。同一路径在多个来源中出现时，运行时优先使用前面的来源；管理页保留全部版本并标记优先来源。搜索覆盖所有加载路径与目录层级。正在执行的节点不会被路径配置操作中断，新的发现与后续加载读取最新配置。

## 文件夹和 Skill

不含 `SKILL.md` 的目录是分类，可继续划分任意层级。含 `SKILL.md` 的目录作为一个完整 Skill 管理，内部脚本、说明和素材不作为分类展开。

可以新建分类、在同一加载来源中移动或重命名整个文件夹。名称遵循运行时路径要求：以字母或数字开头，后续允许字母、数字、下划线、短横线和点。用途说明与正文支持中文。

已有节点、Agent 模板或 Graph 模板引用的 Skill 必须先取消引用，再进行移动、删除或移除加载路径。页面列出相关配置位置，不自动改写已有配置或 Skill 正文中的路径。

## 删除与恢复

删除会把整个目录移动到加载根目录旁的 `.skill-trash/<root-id>/`，管理页的「回收区」提供恢复。不同加载根目录有独立回收记录。恢复不会覆盖同名目录，原父目录必须存在；若父目录也被删除，先恢复父目录。

链接或 junction 不允许通过管理页移动、删除或读取，路径错误、文档格式错误和读取失败会明确显示。说明预览不执行嵌入 HTML，也不自动加载远程图片。
