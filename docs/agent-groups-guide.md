# 在 AgentPark 中使用协作组

协作组是共享计划和任务面板。每个 Agent 继续使用自己的模型、工具、技能和
聊天记录；组本身不占用一个模型，也不会代替成员执行任务。

## 创建和调整成员

1. 在看板上创建需要协作的 Agent，并为各自选择 Provider、模型和工作目录。
2. 框选这些 Agent，按 **G**。它们外面会出现矩形组框，右侧 Graph 面板的
   **Groups** 列表也会出现这个组。
3. 把其他 Agent 拖入组框，松开后加入；拖出组框则离开。归属按节点中心所在
   区域判断。一个 Agent 在同一张图中只能属于一个组。
4. 点击组框内的空白位置、组框标题，或右侧 Groups 条目，打开共享面板。

先把不同组排在不重叠的位置。框选部分已组队成员不会另建一个重叠组。
在文本输入框内输入 G 时不会触发分组。

## 分工、计划和广播

在“计划与目标”中填写组名和共同目标。在“成员正在做什么”中编辑每个成员的
职责，明确产出、文件边界和交接对象。例如：

- 制作人：拆解里程碑、维护整体计划、协调验收。
- 程序：实现运行逻辑，负责指定源码目录。
- 叙事与关卡：制作故事、线索、地图和关卡内容。
- 界面：负责操作、呈现和可访问性。
- QA：独立复现问题、记录证据，验证修复。

共享目录里的文件可以同时被成员访问，因此任务说明应写清楚文件归属；
不应让两个成员未经协调同时修改同一个文件。

下方输入框支持选择接收人。请求处理时，只唤醒选中的成员；明确选择全组
才会群发。“共享动态”只记录信息，不启动任何成员。可以直接说明最终目标、
约束和验收方式，让负责成员通过任务面板拆解、分配和交接。
组和节点使用同一个通用输入框：点击“添加附件”选择图片或文件，也可以
拖放文件、粘贴剪贴板图片或浏览器可读取的剪贴板文件。可以仅发送附件。
上传期间不能发送；发送失败保留文字和附件，重试不会重复发布同一条消息。
附件保存在组内动态中，可预览图片、打开文件，并作为资源随通知送给组员。
任务和消息会保存到组记录中；暂停的成员在恢复后处理待通知内容。

## 查看进展和处理问题

- 桌面组面板左侧是任务、右侧是组内动态，两栏独立滚动。手机通过“任务 / 组内动态”
  切换查看，默认进入动态。成员与计划收在任务栏下方，展开即可查看。
- 组内动态按最新在上排列，打开面板直接看到最新记录；读取旧记录时，新动态不会
  改变当前阅读位置。“加载更早记录”位于动态底部，“回到最新”返回顶部。
- 点击任务就在该任务下方展开配置。已完成任务自动收拢到默认折叠的“归档任务”，
  展开后可查看原始说明、负责人和完成证据；重新打开任务后回到未完成列表。
  归档仅整理显示，保留任务、依赖与历史，不产生额外通知。
- 成员区展示节点运行状态，以及该成员拥有的进行中任务。
- 任务区展示待处理、进行中、受阻、完成状态。点击任务可以编辑负责人、
  说明、状态、前置任务和验证记录。
- Agent 可以读取计划、给指定伙伴发消息、广播、创建任务、认领和更新自己
  的任务。普通进度、证据和计划更新只记录，不唤醒全组。新分配且前置已完成
  的任务只通知负责人，依赖全部完成时只通知下游负责人，不需要发送“收到”。
  Agent 的常用消息工具必须指定接收人；全组行动通知使用独立工具并说明原因。
- 任务有依赖时，需要先完成依赖任务才能开始。标记完成需要填写具体证据，
  例如产出路径、实际测试及结果，不能仅把状态改为“完成”。
- “组内动态”记录交接与变更。通知发生错误时，面板会显示错误记录，便于排查。
- 编辑冲突会明确报错。先保留自己的内容，再查看最新状态，避免覆盖别人的工作。

任务支持分叉和汇合：UI 可以独立推进，角色完成后可以同时解锁动画与外观任务，
集成任务等待自己列出的全部前置完成。每个成员依次处理自己的工作，新任务进入
该成员的待处理队列，不会阻塞其他成员。仅对同一资源、共享编辑器等存在冲突的
操作协调顺序，不把全组工作串成一条流水线。新任务应明确指定负责人和依赖；
未分配任务只作为待办记录，不自动唤醒全组认领。

可以直接在任务区派活：添加标题后，打开任务，选择负责人并保存。就绪任务会
进入该负责人的队列；正在忙的成员处理完当前工作后接着处理，暂停的成员需要
恢复，前置任务尚未完成则等待依赖。保存后的提示和任务行会展示实际投递状态。
用户分配任务的最终答复会回到组内动态，标注“任务答复”，不会再次唤醒其他成员。
修改标题、说明或负责人会通知相应负责人；未改变内容的重复保存不会重新执行。
“任务完成”指该条任务要求已完成：询问现状的任务完成，不代表被询问的项目已经完成。

组员离组后不能继续访问这个组的通信和任务工具。未完成任务会解除该成员的
分配并标记受阻，便于重新安排；已完成任务仍保留历史作者。

## 解除组队

框选某个组的全部成员后再次按 **G**，或者点击右侧 Groups 列表中的“解散”。
组框及成员关系解除，原有 Agent 节点和各自聊天记录保留。
